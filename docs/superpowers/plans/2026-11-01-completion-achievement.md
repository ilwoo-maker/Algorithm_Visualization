# 완료 성취 효과 구현 계획

승인된 설계: 확정된 마지막 스냅샷에서만 각 패널의 완료를 강조한다. Kruskal은 미검사 간선이 남아 있을 때 조기 종료로 표시한다. 실제 속도 경쟁이나 측정값으로 표현하지 않는다.

접근: 기존 재생 훅을 수정하지 않고 패널에서 읽기 전용 기록으로 검사 횟수·선택 수·가중치를 얻는다. CSS 마스킹 conic-gradient 테두리로 1회 회전 후 두 번 펄스하고 정적 보더를 유지한다. Reverse-Delete는 하늘색 fade-in을 적용한다. DOM 테두리 장식은 포인터와 접근성 트리에서 제외한다. CSS 실행이므로 해제 시 타이머나 GSAP 소유자를 남기지 않는다. Reduced Motion은 정적인 보더·배지만 표시한다.

- [x] 완료 이전 비표시, 양쪽 독립 완료, 재탐색 해제·재진입, 동적 횟수·가중치를 테스트한다.
- [x] 패널 배지·요약과 장식 테두리·CSS를 구현한다.
- [x] 전체 테스트·빌드·린트·공백 검사를 실행한다.

코어·스냅샷·재생 시간·SVG 그래프·기존 미커밋 변경은 유지한다. commit/push 없음. 브라우저 자동화는 재시도하지 않으며 실제 화면 모션은 미확인으로 보고한다.

검증: 기존 276개와 신규 4개로 총 20개 파일 280개 테스트 PASS. 마지막 전환 중 미표시 및 commit 후 표시, 재탐색 취소와 재진입, 양쪽 독립성, 다른 입력의 횟수/가중치 및 조기 종료 오표시 방지를 검사했다. build/lint/diff check 성공. 코어·재생 모듈 변경 없음. Reduced Motion은 CSS에서 모션을 제거하며 실제 광선의 화면 렌더링·모바일 가독성은 미확인이다.
