- [x] WHY 카드 단일화와 완료 카드 내부 종료 이유를 검증한다.
- [x] JSX를 통합하고 중첩 박스 없이 본문 서식을 맞춘다.
- [x] 전체 테스트·빌드·린트·공백 검사 및 코어·재생 변경 없음 확인.

commit/push 및 브라우저 자동화 없음. 실제 화면 높이·모바일 가독성은 사용자 확인이 필요하다.
