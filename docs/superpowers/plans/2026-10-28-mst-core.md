# MST Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reproducible, immutable Korean execution traces for Kruskal and Reverse-Delete, verified with Vitest.

**Architecture:** Pure TypeScript; shared graph validation, normalization and BFS; rank/path-compressed Union-Find for Kruskal. Return a discriminated success/error result. Materialize and freeze full snapshots, including connected components, for playback.

**Tech Stack:** Existing TypeScript 7 and Vitest 5; no new dependencies.

**Spec:** User-approved Phase 2 requirements and design in this chat; final API, pseudocode and analysis are documented in `docs/mst-core.md`.

## Global Constraints

- Work on `dev`, initially `b8b7d21e9a6afceb8c89e5d86d0bfe9a322eee56`; initial working tree verified clean, including `index.html` and `vite.config.ts`.
- Preserve README, UI, SVG and GSAP files; no push, PR, merge or deployment.

- Equal weights use normalized edge names in lexicographic order (independent of locale).
- Initial snapshot and every decision; Reverse-Delete also records each temporary removal before deciding.
- Every snapshot has Korean `what` and `why`, a machine-readable reason, edge states, actual active-edge weight and components.
- Reject invalid/disconnected input explicitly; never mutate input or earlier snapshots.
- Test first, observe failure, implement, run full suite, then locally commit each coherent unit.

## Review Focus

- Reversed endpoints and permuted input must produce identical complete traces.
- Empty/singleton graphs, zero/negative/equal weights, malformed runtime inputs and numeric overflow.
- Snapshot objects, nested edges, arrays and components cannot be mutated through caller references.
- Every recorded active graph and component partition must agree, including temporary disconnection.
- Additional small graphs must yield an optimal tree, checked against exhaustive spanning trees.

## Interfaces and files

- `types.ts`: readonly graph, normalized graph, `Result<T>`, errors, edge states and `MstRun`.
- `graph.ts`: `prepareGraph(input: unknown)`, `sortEdges(edges, direction)`, `connectedComponents(vertices, edges)`; one validation path and one BFS implementation.
- `snapshot.ts`: capture and freeze snapshots from a state map; no React/GSAP imports.
- `unionFind.ts`: `UnionFind(vertices)`, `find(vertex)`, `union(a, b)` with path compression/rank.
- `kruskal.ts`, `reverseDelete.ts`: `(input: unknown) => Result<MstRun>`.
- `fixtures.ts`: deeply frozen assignment graph.
- `graph.test.ts`, `unionFind.test.ts`, `mst.test.ts`: real behavior, no mocks.
