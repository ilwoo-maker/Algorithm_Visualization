# Phase 3B — 학습형 알고리즘 애니메이션 설계

기준: `dev`, `40145f04f293b8677e1144368eaed4b506951e32`. 사용자가 승인한 Phase 3B 요구사항을 기록한다.

## 목표와 경계

스냅샷을 설명하는 시각적 전환과 독립 재생을 추가한다. 계산·가중치·연결 요소·한국어 what/why의 유일한 근거는 기존 불변 `Snapshot`이다. 기존 SVG 좌표, 색상, 레이아웃과 최종 결과 비교를 유지한다. 코어·코어 테스트, 입력 편집, 공동 재생, 전체 재설계, 3D, 배포·PDF는 제외한다. 기존 GSAP 3.15.0을 사용하며 신규 의존성은 필요하지 않다.

## 접근 방식

최종 스냅샷의 SVG 속성을 직접 덮어쓰는 방식은 취소 시 React 속성과 충돌할 수 있다. 따라서 정적 간선은 계속 선택한 스냅샷의 속성을 유지하고, 현재 간선 위에 장식용 SVG 선을 겹쳐 전환한다. 필요한 경우 정적 선의 opacity만 잠시 숨긴다. 완료·취소 시 패널 범위의 GSAP context를 revert하여 모든 임시 CSS를 제거한다. 장식 선은 기본 opacity 0이고 접근성 트리에서 제외한다. 별도 알고리즘 상태를 만들지 않는다.

## 3B-1 — 이번 구현

- 사용자 `다음`으로 인접한 다음 스냅샷을 방문할 때만 현재 간선을 애니메이션한다. 초기화·이전·처음·직접 선택·건너뛴 단계는 즉시 표시한다.
- Kruskal 선택: 금색 강조 후 녹색 그리기. 기각: 짧은 강조·붉은 전환 후 기존 붉은 점선.
- Reverse-Delete 임시 제거: 이전 실선을 주황색으로 강조한 뒤 흐리게 하여 스냅샷의 임시 제거 선을 드러낸다. 삭제 확정: 임시 제거 표현을 걷어내고 기존 회색 점선 표시. 복구: 파란 선이 다시 나타난다.
- 수치·표·설명은 전환 시작 시 선택한 스냅샷으로 즉시 갱신한다. `간선 전환 중 · 선택한 단계 기준`을 표시하고 SVG의 busy 상태를 제공한다. 완료 후 전환 표시는 해제한다.
- 각 SVG는 자신의 context와 이전 스냅샷을 소유한다. 새 탐색 시 이전 효과를 먼저 revert하며 오래된 완료 콜백을 무효화한다. 전역 kill은 사용하지 않는다.
- `prefers-reduced-motion: reduce`면 효과를 만들지 않는다. 실행 중 설정이 켜져도 취소하고 정적 최종 상태로 표시한다. StrictMode 재실행과 unmount에서 context·리스너를 정리한다.
- CSS 속성만 임시 변경한다. React가 관리하는 stroke/dash/좌표 등 SVG 속성을 GSAP attr 애니메이션으로 되돌리지 않는다. SVG 좌표의 선 길이를 사용하므로 화면 크기에 독립적이다.

## 3B-2 — 이후 구현, 이번 제외

패널별 재생·일시정지·계속·다시 재생, 0.5/1/2배를 추가한다. 일반 속도는 전환과 설명 읽기 시간을 포함해 단계당 약 2.5초를 기본으로 한다. 한 패널에 활성 타이밍 소유자를 하나만 두고 중복 타이머를 만들지 않는다. 현재 단계부터 순차 방문하고 마지막 단계의 전환이 끝나면 정지한다. 마지막에서 재생하면 초기 상태부터 시작한다. 수동 탐색은 자동 재생을 중단하고 즉시 선택한다. 일시정지는 시각 전환과 읽기 시간을 함께 멈추며 계속 재생은 같은 위치에서 잇는다. 숨겨진 탭에서는 자동 정지하고, 돌아와도 사용자의 명시적 재생 전까지 진행하지 않는다.

## 3B-3 — 이후 통합 검증

기존 124개 회귀, 실제 GSAP 완료·취소·동시 패널·Reduced Motion·StrictMode·unmount를 검증한다. 재생 도입 후 순서·끝·재시작·속도·일시정지·수동 중단·탭 비활성화를 추가 검증한다. Kruskal 최종 8, Reverse-Delete 임시 7 → 복구 11 → 최종 8을 유지한다. DOM 테스트는 실제 렌더링 검증을 대체하지 않는다. 데스크톱·모바일·키보드·콘솔은 허용된 브라우저 검증 또는 사용자 수동 점검으로 별도 확인한다. 이전 Computer Use 안전 중단을 우회하지 않는다.
